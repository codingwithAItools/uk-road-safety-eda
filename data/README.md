# Data

Download the 2025 **Collisions** and **Casualties** CSV files from:

https://www.gov.uk/government/statistical-data-sets/road-safety-open-data

For Google Colab, upload both files directly to the session and keep their original filenames:

- `dft-road-casualty-statistics-collision-2025.csv`
- `dft-road-casualty-statistics-casualty-2025.csv`

For local Jupyter use, place them beside the notebook so the same direct `pd.read_csv()` statements work.

The raw files are not committed because they are large and remain available from the official source.
